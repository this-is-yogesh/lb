The Crux
Computers talk in numbers (IP addresses), but humans talk in words (Domain names). DNS is the internet's phonebook that translates a name like youtube.com into a machine IP like 142.250.80.46.

Why We Need DNS (The 4 Value Pillars)
Human Readability: It is easier to memorize amazon.com than 205.251.242.103.

IP Flexibility: If a server's IP changes, the domain name stays the same. DNS absorbs the change seamlessly.

Load Distribution: DNS can point one domain name to hundreds of different server IPs to split traffic.

Geo-Routing: DNS sends users to the closest server geographically to reduce lag.

Input: Domain Name (youtube.com) ->DNS Lookup->Output: IP Address (142.250.80.46)
