1. some() - "Does at least ONE element satisfy the condition?" , returns
either true or false
2. every() - "Do ALL elements satisfy the condition?", returns true or false
3. findIndex() - index of first matching element, nums.findIndex(num => num === 20);
4. indexOf() - returns first index , [1,2,3].indexOf(2)
5. how to use Array.from() 
Array.from({ length: totalPages }, (_, i) => i + 1)
